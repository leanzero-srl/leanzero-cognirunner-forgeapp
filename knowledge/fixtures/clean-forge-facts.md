# Forge platform facts

A synchronous resolver has 25 seconds; the async consumer has 120, and the long consumer
900. One KVS value holds at most 240 KiB, so a registry that lives in a single value needs
caps rather than eviction. On issue create the issue key is null, so read the modified
fields instead of fetching.

Call the REST API as the app with `asApp()`. The site is addressed as
https://your-domain.atlassian.net and the account used in the examples is mia@example.com.
